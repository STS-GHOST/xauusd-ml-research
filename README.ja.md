# xauusd-ml-research

![tests](https://github.com/STS-GHOST/xauusd-ml-research/actions/workflows/tests.yml/badge.svg)

[English](README.md) | **日本語**

XAUUSD（金・ドル）1時間足に対する、CatBoost を使った方向予測モデルの検証記録です。MetaTrader 5 用 EA への実装まで含みます。

## 結論：エッジは検出されませんでした

purge/embargo 付きウォークフォワードで 2021-01〜2026-07 を全てアウトオブサンプル化して評価した結果：

| | 値 |
|---|---|
| ドリフト条件付き偏IC（全期間） | **−0.0002** |
| 95% 信頼区間 | **[−0.0195, +0.0193]** |
| サンプル数 | 32,947 バー |
| 運用に必要な水準 | IC ≥ 0.029（**信頼区間の外**） |

トレードあたりの期待値に換算すると：

```
信号の 95% 上限   +0.059 ATR
摩擦の下限        +0.053 ATR   (スプレッド 0.027 + 損切り 0.027)
                  ─────────────
最良ケースで損益分岐。運用に足りません。
```

**「まだ判定できない」ではなく「探していた大きさの効果は、この特徴量セットには入っていない」**という結論です。

このリポジトリは、その否定的な結論に至るまでの測定基盤と、途中で見つけて修正した自分の誤りを残すために公開しています。右肩上がりの損益曲線はありません。

## なぜ否定的な結果を公開するのか

この題材で実際に時間を使ったのは、モデルの改良ではなく**測定の設計**でした。

当初の評価は「横ばい期（2021-22）は負け、上昇期（2023-26）は勝つ」という結果を示していました。これは誤りで、原因は次の1行でした。

```python
XAU_M1_PATH = "XAUUSD_M1_202301030100_202607312354.csv"   # 2023-01-03 開始
...
model.fit(X, y)                                           # ホールドアウトなし
```

**学習データが 2023 年開始だったため、「上昇期で勝つ」の評価区間が丸ごと in-sample でした。**正しくウォークフォワード化すると、レジーム差そのものが消えました。

同種の問題が他にもありました。

- ウォークフォワードに purge/embargo がなく、ラベルが `shift(-6)` なのでフォールド境界ごとに 6 本の漏れがあった
- 自作の検証コードで建玉タイミングを 1 バーずらし、先読みを混入させた（結論 2 件が反転）
- 超過リターンを評価目標にしたところ、定義上の機械的バイアスで偽の負の IC が出た
- ATR を Python 側で SMA、MQL5 側で Wilder にしていた（平均絶対差 10.17%）

**いずれも「もっともらしい数字」を出していました。**気づいたのは、帰無仮説ではなく**ポジティブコントロール**を置いてからです。

### テストについて

テストはすべて、**実際にやらかした誤りに1対1で対応しています。**

```bash
pip install -r requirements.txt pytest
pytest tests/ -v
```

特に 2 つ。

**`test_excess_target_is_biased_but_partial_ic_is_not`**
「純粋にドリフトを追うだけのスコア」というポジティブコントロールを流します。これは「ドリフト以外の信号」の指標で 0 になるはずですが、超過リターンを目標にすると系統的に **−0.06** が出ます。探している効果の 2 倍の大きさの偽の負値です。**この欠陥は帰無テストでは検出できません**——無意味なスコアはどちらの指標でも 0 になるので。

**`test_signal_bar_data_cannot_affect_pnl` / `test_entry_bar_open_does_affect_pnl`**
バー t のデータを壊しても損益が変わらないこと、かつバー t+1 のデータを壊せば必ず変わること。後者がないと、前者は「何も使っていない」実装でも通ってしまいます。

## 手法

| 項目 | 内容 |
|---|---|
| 対象 | XAUUSD H1、2020-01〜2026-07（38,947 本） |
| 特徴量 | `ret_1/3/6`, `dist_ma50/200`, `rsi`, `atr_ratio`, `hour`, `dayofweek` |
| ラベル | 6 本先リターン / ATR、±0.5 ATR の中立帯を除外した二値 |
| モデル | CatBoost（depth=4, l2=30, 300 iterations, lr=0.05）× 5 シード平均 |
| 評価 | 22 フォールドの拡大窓、purge=6 本、embargo=24 本 |
| 主指標 | ドリフト（過去 500 本）を条件付けた偏IC |
| 不確実性 | ブロックブートストラップ（ブロック長はスコアの実測半減期から決定） |
| コスト | ティックデータ由来の実スプレッド（固定値の仮定を置かない） |

### 偏IC を使う理由

超過リターン `fwd − h·drift(N)` を目標にすると、スコアがドリフトと相関 ρ を持つ場合に

```
機械的成分 = −ρ · h/√(N·h) = −ρ × 0.110     (N=500, h=6)
```

が乗ります。そこでスコア側と目標側の**両方から**ドリフトを落とす偏相関を使っています。独立 8 ドローで平均 +0.0015（標準偏差 0.0085）、無偏であることを確認済み。

同じ算数は学習ラベルにも効きます。ラベルに `−h·drift` を入れると、その項はラベル標準偏差の 11% を占め、`dist_ma200` 等からほぼ再構成できます。勾配ブースティングは真っ先にそこを食い、「直近ドリフトの逆張り」という実在しない事前分布を学習します。**したがって学習ラベルは生のリターン、評価だけ偏IC** という構成にしています。

## 何が効いていて、何が効いていなかったか

生の信号から実損益までを段階分解した結果（2021-22、ATR 単位）：

| 段階 | 寄与 | 判定 |
|---|---|---|
| スプレッド | **−0.026** | 確定（CI 幅 0.002） |
| 損切り 3 ATR | −0.027 | 判定不能 |
| 1 ポジション制約 | −0.106 / +0.018 | **不安定**（未解決） |
| `atr_ratio ≥ 1.10` フィルタ | **−0.091** | 下記 |

`atr_ratio` フィルタは、3 水準 × 2 レジームの 6 セルすべてで「絞るほど悪化」の向きに揃いました。個別セルはいずれも判定不能ですが、支持する証拠がなく標本の 54% を捨てるため、**統計的勝利ではなく設計判断として無効化**しています（EA の既定値を 1.10 → 0.00 に変更）。

コストの実測値は 0.0156〜0.0245 ATR で、研究コードが置いていた `COST_ATR = 0.0287` は約 1.3 倍過大でした。

## データについて

**価格データは含まれていません。**M1 ヒストリカルデータはブローカーからライセンス供与されたもので、再配布できません。

実行するには、MT5 から XAUUSD の M1 データをタブ区切り CSV で書き出し、`<DATE> <TIME> <OPEN> <HIGH> <LOW> <CLOSE> <TICKVOL> <VOL> <SPREAD>` の列を含む形でリポジトリ直下に置いてください。

```bash
python3 src/walk_forward.py --m1 XAUUSD_M1_<範囲>.csv --out model_scores_wf.csv
python3 src/ic_report.py    --m1 XAUUSD_M1_<範囲>.csv --score model_scores_wf.csv
python3 src/wrapper_decomp.py --m1 XAUUSD_M1_<範囲>.csv --score model_scores_wf.csv
```
